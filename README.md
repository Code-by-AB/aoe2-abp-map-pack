# AbP Map Pack

Custom random map scripts for Age of Empires II: Definitive Edition.

> **These are not original creations.** Almost every map here is an official or
> community map with small tweaks added, so credit for the underlying maps belongs
> to their original authors ([Credits](#credits)) — ask and anything comes down.

## Install

Close AoE2 DE, then open [`update.ps1`](update.ps1), click **Raw** to save it and
right-click the saved file → **Run with PowerShell**. That installs the pack, and
running it again any time updates it. Start the game and the maps are under
**Custom maps**. Nothing else to install — no Git, no accounts.

## Lobby notes

- The Trio maps and Burrito Brawl 4v4 need **two real teams of 2+ players** — AoE2
  does not count a 1-player team as a team, so they cannot generate a 1v1 or an FFA.
- Burrito Brawl 4v4 wants **Large** or bigger.
